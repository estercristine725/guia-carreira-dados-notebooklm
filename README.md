## Contexto e Objetivos

Este repositório foi criado para documentar minha jornada de transição de carreira da Engenharia para a área de Tecnologia, com foco em Análise de Dados.

O principal objetivo deste projeto é reunir, de forma organizada, os conhecimentos, materiais de estudo, exercícios e projetos desenvolvidos ao longo desse processo de aprendizagem. Além de servir como um registro da minha evolução, este repositório também busca funcionar como um guia de estudos para estudantes e profissionais que desejam realizar a mesma transição de carreira.

Ao longo deste caderno temático, serão abordados conceitos fundamentais de Análise de Dados, ferramentas, linguagens de programação, bancos de dados, Business Intelligence (BI) e outros conteúdos relevantes para a formação de um profissional da área.

## Engenharia de Prompts e Cicatrizes

> **Prompt Inicial**
>
> Quais ferramentas um analista de dados precisa saber?

**Resposta obtida**

Uma lista genérica contendo Excel, SQL e Power BI.

> **Refinamento (Prompt Estratégico)**
>
> Como posso utilizar meu conhecimento em manutenção de equipamentos mecânicos para criar um portfólio de análise de dados que resolva o problema de paradas não planejadas?

**Resposta obtida**

Troubleshooting: Inicialmente, a IA pode focar apenas em "dashboards bonitos". A dificuldade foi forçá-la a conectar Storytelling com indicadores de manutenção (KPIs) e Machine Learning  


## Glossário de Conceitos Aprendidos

| Conceito | Definição |
|----------|-----------|
| SQL | Linguagem para consulta e manipulação de bancos de dados relacionais. |
| DAX | Linguagem de fórmulas utilizada no Power BI. |
| Manutenção Preditiva | Técnica que utiliza dados para prever falhas. |
| SVM | Algoritmo de Machine Learning para classificação e regressão. |
| Transformada de Wavelet | Técnica para análise de sinais em diferentes frequências. |

## Principais Aprendizados

Ao desenvolver este caderno temático, compreendi que:

- SQL é uma das habilidades fundamentais para iniciar na área de dados;
- Conhecimento de negócio é um diferencial competitivo;
- Um bom analista resolve problemas, não apenas cria dashboards;
- Projetos práticos possuem maior peso do que certificados isolados;
- Engenharia Mecânica e Análise de Dados possuem diversas conexões por meio da manutenção preditiva, indicadores e otimização de processos.
